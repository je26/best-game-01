Coralhold — Defend the Heart Reef. An original tower-defence game with a hero you swim: 6 coral towers with 3 tiers each, 8 enemy kinds, 15 waves with leviathan bosses, draft boons between waves, 3 difficulties, and procedural WebAudio sound and generative music. No assets, no network: every pixel and note is drawn and synthesized in code. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Play with keyboard and mouse: WASD to swim, hold the mouse button to shoot bubbles, keys 1-6 to pick towers, Space to dash, Q for a shockwave.
